# 🎓 Thapar University RAG System

A **Retrieval-Augmented Generation (RAG)** based AI assistant that answers questions about **Thapar Institute of Engineering & Technology (TIET)** using university-specific data.

## 🚀 How It Works

```text
User Question
     ↓
Query Embedding
     ↓
Vector Database
     ↓
Relevant Documents
     ↓
LLM
     ↓
Answer
```

## 📚 Data Sources

The system can use:

* University website
* Academic documents
* Notices
* Admission information
* Course details
* Hostel information
* FAQs

## 🛠️ Tech Stack

* **Python**
* **RAG**
* **Vector Database**
* **Embeddings**
* **LLM**
* **FastAPI / Streamlit**

## 💡 Example

**Question:**

> What is the admission process at Thapar University?

The system retrieves relevant university information and generates an answer based on that context.

## 🎯 Goal

To provide students with a **fast, reliable, and university-specific AI assistant** for finding information about Thapar University.
